# Диагностика и исправление: пульс не синхронизируется

## Проблема

Android Companion App не синхронизирует данные о пульсе с Sleep Monitor, хотя шаги и сон приходят нормально.

## Две вероятные причины

### 1️⃣ **Health Connect не получает пульс от Mi Fitness** (вероятность 95%)

Это проблема конфигурации, а не кода приложения.

#### Проверка

1. Откройте на телефоне **Здоровье и спорт** (Google Health/Health Connect)
2. Перейдите в **Просмотр данных** → **Пульс**
3. Выберите **сегодня**
4. **Есть ли там значения пульса?**
   - ✅ **ЕСЛИ ДА** → переходите к причине #2 (проблема в коде)
   - ❌ **ЕСЛИ НЕТ** → Mi Fitness не синхронизирует пульс в Health Connect

#### Решение (если в Health Connect пусто)

**Попробуйте сбросить синхронизацию:**

1. Откройте **Mi Fitness** на телефоне
2. Settings → **Sторонние приложения** / **Third-party apps** → **Google Health Connect** (или **Health Sync**)
3. Нажмите **Отключить** / **Disconnect**
4. Когда система попросит подтвердить, нажмите **OK** (отключить для всех данных)
5. Заново нажмите **Включить** / **Connect**
6. **ВАЖНО:** Убедитесь, что вы выбрали ВСЕ ТРИ разрешения:
   - ✅ Steps
   - ✅ Sleep
   - ✅ **Heart Rate** (это обязательно!)
7. Нажмите **OK**
8. В Mi Fitness найдите кнопку **"Синхронизировать с браслетом"** и нажмите **"Sync"**
9. Подождите **30 секунд**
10. Откройте Health Connect заново и проверьте, появился ли пульс

**Если всё ещё не помогает:**

1. Settings → Apps → **Mi Fitness** → **Force Stop**
2. Settings → Apps → **Mi Fitness** → Storage → **Clear Cache** (не Clear Data!)
3. **Перезагрузите телефон**
4. Откройте Mi Fitness, синхронизируйте данные заново
5. Проверьте Health Connect

---

### 2️⃣ **Приложение неправильно запрашивает пульс из Health Connect** (вероятность 5%)

Если в Health Connect **видны данные пульса**, но приложение их не синхронизирует → проблема в коде `SyncHelper.kt`.

#### Текущая проблема в коде

Приложение использует `AggregateRequest` с `HeartRateRecord.BPM_AVG`, но эта метрика может быть недоступна в Health Connect.

**Решение:** Использовать `ReadRecordsRequest` для чтения **индивидуальных измерений** пульса и вычисления среднего вручную.

#### Как применить исправление

1. **Замените `SyncHelper.kt`** на исправленную версию (смотрите файл ниже)
2. **Пересоберите APK:**
   ```bash
   cd android_sync_app
   ./gradlew assembleDebug
   ```
3. **Переустановите приложение:**
   ```bash
   adb install -r app/build/outputs/apk/debug/app-debug.apk
   ```
4. **Протестируйте** — должны быть логи типа `Heart rate average: 72 BPM (from 240 samples)`

## 📁 Исправленный код

Ниже приведена исправленная версия `SyncHelper.kt`. Главное изменение — метод `fetchHeartRateAverage()`:

```kotlin
/**
 * Fetch heart rate average for the day using ReadRecordsRequest.
 * Reads individual measurements and calculates average.
 * Returns 0 if no heart rate data is available.
 */
private suspend fun fetchHeartRateAverage(
    client: HealthConnectClient,
    startOfDay: java.time.Instant,
    endOfDay: java.time.Instant
): Int = kotlinx.coroutines.withContext(kotlinx.coroutines.Dispatchers.IO) {
    try {
        val hrRecordsRequest = ReadRecordsRequest(
            recordType = HeartRateRecord::class,
            timeRangeFilter = TimeRangeFilter.between(startOfDay, endOfDay)
        )
        val hrRecords = client.readRecords(hrRecordsRequest).records

        if (hrRecords.isEmpty()) {
            Log.w("SyncHelper", "No heart rate records found for the day")
            return@withContext 0
        }

        // Collect all BPM samples from all records
        val allBpmSamples = mutableListOf<Int>()
        for (record in hrRecords) {
            for (sample in record.samples) {
                allBpmSamples.add(sample.beatsPerMinute.toInt())
            }
        }

        if (allBpmSamples.isEmpty()) {
            Log.w("SyncHelper", "No BPM samples found in heart rate records")
            return@withContext 0
        }

        val avgBpm = allBpmSamples.average().toInt()
        Log.i("SyncHelper", "Heart rate average: $avgBpm BPM (from ${allBpmSamples.size} samples)")
        avgBpm
    } catch (e: Exception) {
        Log.e("SyncHelper", "Error fetching heart rate: ${e.message}", e)
        0
    }
}
```

Полный исправленный файл находится в приложении Android Studio или в отдельном файле `SyncHelper_fixed.kt`.

## 🔍 Отладка

Если ничего не помогает:

1. Откройте **Android Studio** → **Logcat**
2. Фильтр: `SyncHelper`
3. Нажмите **"Sync Now"** в приложении
4. Ищите сообщения:
   - `Heart rate average: X BPM (from Y samples)` — ✅ пульс найден, но может не синхронизироваться на сервер
   - `No heart rate records found for the day` — ❌ Health Connect не содержит данные пульса за этот день
   - `Error fetching heart rate` — ⚠️ ошибка при чтении из Health Connect

Это поможет определить, на каком этапе происходит разрыв.
