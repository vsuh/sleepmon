# Доступные метрики в Health Connect API

Вот полный список того, что можно получить из Health Connect кроме шагов, пульса и сна.

---

## 📊 Текущие метрики (реализовано)

✅ **Steps** — количество шагов за день  
✅ **Heart Rate** — средний пульс (BPM)  
✅ **Sleep** — длительность ночного сна (часы)

---

## 💪 Активность и физическая активность

### ExerciseSessionRecord
- **Тип:** `ReadRecordsRequest` (списки сессий, не агрегированное значение)
- **Примеры:** бег, ходьба, велосипед, плавание, йога, силовые тренировки
- **Данные:** время начала/конца, тип упражнения, сожженные калории, средний пульс
- **Интеграция:** ✨ **Рекомендуется** — пользователь может видеть типы упражнений

---

## 🔥 Энергия и калории

### Calories (Energy)
- **Метрика:** `EnergyRecord.ENERGY_KJOULES` или `ENERGY_CALORIES`
- **Два типа:**
  - **Active calories** — сожженные при упражнениях
  - **Total calories** — активные + базовый метаболизм
- **Интеграция:** можно добавить как отдельное поле (`calories_burned`)

```kotlin
val caloriesReq = AggregateRequest(
    metrics = setOf(EnergyRecord.ENERGY_KJOULES),
    timeRangeFilter = TimeRangeFilter.between(startOfDay, endOfDay)
)
val caloriesResp = client.aggregate(caloriesReq)
val calories = caloriesResp[EnergyRecord.ENERGY_KJOULES]  // в килоджоулях
```

## 💧 Гидратация

### Hydration
- **Метрика:** `HydrationRecord.VOLUME_MILLILITERS`
- **Единица:** мл (обычно 2000-3000 мл в день)
- **Интеграция:** можно отслеживать как отдельное поле

---

## 🫀 Здоровье сердечно-сосудистой системы

### Blood Pressure
- **Метрики:** `BloodPressureRecord.SYSTOLIC` / `DIASTOLIC`
- **Единица:** mmHg (давление в мм ртутного столба)
- **Примеры:** 120/80, 110/70
- **Примечание:** требует браслета с датчиком АД (Mi Band 8+)

### Oxygen Saturation (SpO2)
- **Метрика:** `OxygenSaturationRecord.PERCENTAGE`
- **Типичное значение:** 95-100%
- **Примечание:** редко, требует специального датчика

---

## ⚖️ Вес и антропометрия

### Weight
- **Метрика:** `WeightRecord.WEIGHT_KILOGRAMS`
- **Интеграция:** для отслеживания тренда веса

### Height
- **Обычно:** записывается один раз, не требует регулярного обновления

---

## 🧠 Стресс и дыхание

### Respiratory Rate
- **Метрика:** `RespiratoryRateRecord.RATE`
- **Единица:** дыхания в минуту (12-20 — норма)
- **Примечание:** редко доступно в браслетах

---

## 💤 Детали сна (расширенно)

### Sleep Stages
- **Текущая реализация:** читаем только общее время сна
- **Возможное улучшение:** разделить на Awake, Light, Deep, REM фазы

```kotlin
// Текущая реализация:
val sleepHours = (longest.endTime - longest.startTime) / 3600000.0

// Возможная расширенная версия:
for (record in sleepRecords) {
    for (stage in record.stages) {
        // stage.type = LIGHT, DEEP, REM, AWAKE
        // stage.startTime, stage.endTime
    }
}
```

- 🔮 **Blood Pressure** — для пользователей с гипертонией

## 🛠️ Как добавить новую метрику

Смотрите примеры в `app/main.py` для `/sync` эндпоинта и `SyncHelper.kt` для чити данных из Health Connect.

**Основные шаги:**
1. Прочитать метрику из Health Connect в `syncSingleDay()`
2. Отправить на сервер в `postToServer()`
3. Добавить обработку на сервере в `main.py` (параметр формы → frontmatter)
4. Обновить веб-форму (если нужно редактировать вручную)
